Пример расширения для Google Chrome, которое собирает данные с сайта rashod.ru.
Как использовать.
* разархивировать в любую папку;
* в Google Chrome перейти по адресу chrome://extensions/ ;
* загрузить распакованное расширение;
* выбрать папку с распакованным расширением;
* проверить что оно появилось в списке "Все расширения" и включено;
* перейти по ссылке из списка ниже. Тестировал на https://rashod.ru/brother/

Отключатся картинки и стили. Будет автоматическое листание страниц и выгрузка данных в папку "Загрузки", "rashod.ru" в формате JSON.
Вся процедура длится не долго. Зависит от скорости Интернет, сайта и прочего.
Форматируется и выгружается информация в виде полей: art, brand, title, href, price.
Получается такая вкуснятина для загрузки в БД (rashod.ru.brother.zip).
